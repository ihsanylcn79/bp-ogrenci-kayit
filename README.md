# Öğrenci Kayıt Otomasyonu (bpOgrenciKayit)

Bayburt Üniversitesi Bilgisayar Programcılığı dersi için geliştirilen C# Windows Forms (.NET 10) öğrenci kayıt uygulaması.

## Özellikler
- Öğrenci ekleme, güncelleme, silme ve listeleme
- SQL Server LocalDB (`(localdb)\MSSQLLocalDB`) üzerinde `OgrenciKayitDB` veritabanı ve `OgrencilerX` tablosunun otomatik oluşturulması

## Çalıştırma (.exe)
Visual Studio olmadan çalıştırmak için sağdaki **Releases** bölümünden `MuhammetIhsanYalcin_Vize.zip` dosyasını indirin, **Tümünü ayıkla** ile açın ve `bpOgrenciKayit.exe` dosyasına çift tıklayın.
